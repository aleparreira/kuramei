# Kuramei Manifesto — Alpha v0.2

Kuramei existe para resolver a vida real no WhatsApp.
Sem prompt complexo. Sem fricção. Sem enrolação.

Não somos “mais um chat de IA”.
Somos um assistente pessoal que recebe pedido simples, executa e devolve resultado útil.

## Para quem é

Para quem vive no WhatsApp e quer resolver o dia com menos esforço.

## Para quem não é

Para quem quer brincar de ferramenta. Kuramei é para uso, não para demonstração.

## Problema que resolvemos

Hoje, pedir ajuda digital dá trabalho demais e entrega de menos.
Texto longo, ação curta.

## Promessa do produto

Você fala naturalmente.
Kuramei entende contexto, age e retorna algo utilizável em segundos.

## Princípios inegociáveis

1. Simplicidade radical para o usuário.
2. Ação antes de explicação.
3. Utilidade acima de “resposta bonita”.
4. Segurança por design (LLM não executa código gerado).
5. Evolução contínua com uso real.

## O que não vamos fazer

- Consultoria disfarçada de produto.
- Escopo inflado sem validação.
- Feature para impressionar, não para resolver.

## Quando está pronto para vender

- Usuário novo entende em 1 minuto.
- Fluxos principais funcionam sem intervenção.
- O usuário volta porque confia.

## Como vamos construir

Ciclos curtos: construir, testar, corrigir, repetir.
Menos discurso. Mais produto funcionando.

Kuramei não precisa nascer perfeito.
Precisa nascer útil — e melhorar toda semana até virar indispensável.
